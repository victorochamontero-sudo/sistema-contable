🧨 Zona de borrado

⚠️ Estas acciones son irreversibles. Antes de borrar, el sistema descargará automáticamente un respaldo JSON de seguridad.

🗑 Borrar por tipo de movimiento

Elige qué tipo de registros quieres eliminar. Los demás se conservan.

🗑 Borrar por rango de fechas

Elimina los movimientos cuya fecha esté entre las fechas indicadas (incluyendo ambas).

🧹 Borrar TODOS los movimientos

Elimina todos los movimientos pero conserva el catálogo de configuraciones.

🧨 Borrar TODO el sistema

Elimina TODOS los movimientos y reinicia el sistema a cero. Se descargará un respaldo antes de borrar.
